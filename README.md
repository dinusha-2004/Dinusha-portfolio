# 🌐 Personal Portfolio Website — AWS Cloud Hosted

A personal portfolio website built with HTML, CSS, and JavaScript, deployed on AWS using S3 static website hosting and CloudFront CDN.

## 🚀 Live Demo
- **CloudFront (HTTPS):** https://d2taj3d8buvwii.cloudfront.net
- **S3 URL:** http://dinusha-portfolio.s3-website.eu-north-1.amazonaws.com

## 🛠️ Tech Stack
- HTML5, CSS3, JavaScript
- AWS S3 — Static website hosting
- AWS CloudFront — CDN + HTTPS
- AWS IAM — Security best practices

## ☁️ AWS Architecture
User → CloudFront (HTTPS) → S3 Bucket → Static Files

## 📌 Features
- Responsive design
- HTTPS secured via CloudFront
- Global content delivery via AWS Edge locations
- Billing alerts configured
